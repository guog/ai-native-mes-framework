# 模块化 GraphQL 契约规范 · Draft V0.2

**ADR：** 066、068～072、078～079、085、088～090、115。

## Schema 注册与切换

- 模块声明公开类型、Query、Mutation、Resolver 和所有权；组合期校验同名冲突、权限及类型兼容。
- 先构建不可变 Schema 快照并校验，再原子切换当前实例入口；HA 节点逐步就绪并允许受控兼容窗口。
- 插件停用期间保留已承诺的兼容字段，但执行必须返回安全“不可用”，不得调用已停用插件；到期字段可按契约移除。
- Mutation 必须映射权威业务动作契约；Query 必须映射显式读取模型与受控查询服务，不暴露 ORM 实体内部细节。

## 统一权限与限额

可信 Context 包含身份、工厂、资源作用域、授权版本、请求/关联 ID、超时与预算；字段级及资源级权限都由服务端强制。

每一入口须支持深度/复杂度、分页上限、超时、并发/请求预算；高风险查询可持久化操作白名单。不得让外部客户端通过嵌套字段获取未经授权的关联资源。

## 兼容性测试

- 对比两代 Schema：新增/弃用、非空性变化、字段/参数类型变化、名称所有权变化。
- 提交中的旧请求安全完成或按明确规则中止，不调用已停用代际。
- Query/Mutation 在 HA 双代际兼容窗口中由请求路由和就绪策略保障，测试 GraphQL 非空错误传播。
- 资源治理应在恶意高复杂度 Query、深度嵌套、跨工厂请求中拒绝风险操作。
