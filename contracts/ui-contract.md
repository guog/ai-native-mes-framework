# Vue 声明式 UI 与插件槽位契约 · Draft V0.2

**ADR：** 005、048、063～064、075、081、085、094。

## 配置模型

提供基础配置→客户扩展→工厂覆盖的层级，标识 UI 配置版本、依赖的 GraphQL 读取契约、Action ID、字段类型、展示规则及权限要求。配置用于表单/列表/报表和普通显示逻辑，不作为关键业务规则或数据库写入代码。

## 动态装配

可信模块的路由、菜单、UI Slot 通过版本化 API 注册；低信任 UI 在 iframe 等隔离上下文，使用限制来源、结构化消息和最小能力权限；禁止传递宿主高权限令牌。

## 验收

版本覆盖冲突、客户/工厂配置回滚、插件停用后的禁用页面、跨工厂缓存泄漏、iframe 越界与 GraphQL 授权失效。界面可见性不能作为服务端授权的证明。
