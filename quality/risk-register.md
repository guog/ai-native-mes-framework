# 架构风险与待验证事项（V0.1）

> 下列状态均为 `待验证`。没有执行过生产故障试验、数据库认证或安全压测，不得表示为已通过。

## P0-01 · 零已确认生产事务丢失

- 关联：ADR-107、ADR-113、ADR-119、ADR-120、ADR-126、ADR-129。
- 风险：同步副本失联、写入结果不确定、节点存储故障、错误故障切换造成已确认事务丢失或脑裂。
- 验证：各数据库×版本×部署组合故障注入、稳定业务请求 ID 查核、审计/业务/Outbox 一致性核验。
- 失败处理：拒绝关键新写入，禁止无认证组合冒称 RPO=0；重新选择认证持久化方案。
- 状态：待验证。

## P0-02 · Kysely + 达梦 dmdb 适配

- 关联：ADR-047、ADR-086、ADR-093、ADR-117、ADR-123。
- 风险：方言、DDL、事务、锁、数据类型及迁移不一致。
- 验证：Dialect 驱动/SQL 编译/适配/探查及事务、迁移、Outbox、Worker 真实达梦测试。
- 失败处理：通过持久化契约切换经测试的 dmdb/SQL 受控专属适配，保留四库目标。
- 状态：待验证。

## P0-03 · 跨四数据库的 Worker 与 Outbox

- 关联：ADR-049、ADR-092、ADR-118、ADR-122。
- 风险：并发领取、租约续约、旧 Worker 延迟写入、重复副作用及停机补偿语义不一致。
- 验证：真实数据库并发及故障注入、租约失效保护、重复执行幂等测试。
- 失败处理：按数据库实现已验证的专属原语，避免一套 SQL 假定所有库等价。
- 状态：待验证。

## P0-04 · 插件与 Agent 隔离

- 关联：ADR-024、ADR-042、ADR-083、ADR-095、ADR-110、ADR-130。
- 风险：客户插件数据库越权、跨工厂读取、绕过关键受控业务动作、Agent 审批与参数不一致。
- 验证：负向安全测试、隔离故障测试、授权撤销执行时复核、数据库最小权限试验。
- 失败处理：阻断安装/发布或禁用受影响能力；不得以签名替代权限隔离。
- 状态：待验证。

## P0-05 · 动态 GraphQL 生命周期

- 关联：ADR-017、ADR-069、ADR-078、ADR-088、ADR-089、ADR-115。
- 风险：Schema 原子切换中旧请求损坏、停用插件仍被调用、多实例版本兼容窗口不正确。
- 验证：Schema 热发布、跨实例版本演进、客户端兼容、停用后不可用错误和在途安全处理测试。
- 失败处理：保留旧快照、拒绝发布或进入受控维护窗口。
- 状态：待验证。

## P1-01 · 性能容量指标仍未数值化

- 关联：ADR-099、ADR-125、ADR-128。
- 风险：没有基准负载和硬件/数据规模时，P95、同步积压、吞吐量无法承诺。
- 验证：定义参考业务测试模块、标准负载及规模分级，再记录具体指标和结果。
- 状态：待定义指标，待验证。

## P1-02 · 长时离线与权限更新滞后

- 关联：ADR-039、ADR-052、ADR-067、ADR-099。
- 风险：长期断网期间中心撤销未即时抵达、本地事件积压容量不足。
- 验证：权限有效期、本地紧急撤销、断网容量计算、断网恢复后对账。
- 状态：待验证。


## V0.2 补充：风险结果与证据规则

- 文档内任何“必须”“目标”不等于已有测试结果。
- **P0-R1**：零确认事务丢失/同步存储/仲裁故障需逐组合故障注入（ADR-107、119、120、126、129）。
- **P0-R2**：达梦 dmdb + Kysely 方言的 Driver/DDL/事务/锁能力未证实（ADR-117、123、127）。
- **P0-R3**：主库 Worker 租约及外部副作用幂等在四数据库间待验证（ADR-118、122）。
- **P0-R4**：客户插件隔离及关键表不可绕过访问需要 OS、数据库和 API 多层负向测试（ADR-110、130）。
- **P0-R5**：高可用 GraphQL Schema 双版本窗口兼容、旧任务恢复需验证（ADR-078、082、089）。
- **P1-R6**：参考负载的硬件、数据集、P95/吞吐、离线时长尚待正式评审填值（ADR-125、128）。
