# 第 11 章 · Vue 前端和声明式 UI

**状态：** 规格草案。**ADR：** 005、032、048、063～064、069～072、075、081、085、088～090、094。

## 11.1 统一应用壳

采用统一 Vue 应用壳，提供身份会话、工厂上下文、导航菜单、主题/国际化、受控 GraphQL Client、错误处理及统一前端追踪。业务模块注册自己的菜单、路由、页面和 UI 插槽；不得借注册接口修改其他模块内部状态或绕过服务端授权。

统一壳的导航权限是用户体验控制，而非安全边界。任何隐藏菜单的操作仍必须在 GraphQL 查询服务和应用动作服务中进行字段、资源和工厂级权限校验。

## 11.2 声明式 UI 的能力边界

- 配置适用于表单、列表、报表、页面布局、展示规则和一般交互；核心生产事务、复杂业务状态机、关键写入和审批判定以可测试代码实现。
- 声明式配置必须能标识对应公开 Query/Action Contract 和字段版本；不可允许配置任意 SQL、任意服务器端表达式或注入 JavaScript 以直接修改生产状态。
- 配置分为基础产品、客户扩展、工厂覆盖层；合并策略和冲突必须显式，不允许“最后保存者静默覆盖所有层”。
- 配置变更支持校验、差异预览、审计、回滚。安全/关键行为相关配置需要受控发布；普通展示类配置可动态生效。

## 11.3 动态插件 UI

- 可信 UI 通过路由、菜单、插槽的公开契约集成；依赖声明中注明宿主 UI SDK 和数据契约版本。
- 客户/低信任 UI 在 iframe 等隔离文档中运行；使用严格来源/消息类型/调用能力白名单和受控会话凭据；不得暴露父窗口权限 Token 或数据库凭据。
- 插件禁用要同步从导航撤销入口；已有页面应安全退出或转到明确“功能不可用”状态，兼容期内 GraphQL 字段存在并不代表插件仍可操作。
- 多实例 Schema 滚动发布的兼容窗口，前端客户端必须能够遵循版本与字段废弃规则，不能假定任何时刻所有节点完全同版本。

## 11.4 数据加载与实时更新

- GraphQL 是默认业务读取和写入接口。GraphQL Subscription/推送作为可选官方模块，缺失时可轮询降级。
- 页面不直接访问高频工业设备采集通道作为未经治理的写入路径；设备数据适配独立服务。
- 查询必须设分页上限、请求取消、超时预算、错误边界和 UI 防重复提交；不可依赖前端取消来保证事务取消。

## 11.5 测试与验收

- 声明式 UI 配置版本前后兼容、不同覆盖层优先级与回滚结果一致。
- 低信任 iframe 尝试跨域读取父页面、伪造消息、修改工厂上下文：应被阻断。
- 客户端切换工厂时缓存必须隔离，不得把其他工厂数据作为查询结果闪现或复用。
- GraphQL 字段禁用/废弃和长请求超时必须有明确用户状态，不静默重复 Mutation。

**待进一步细化的契约文件：** `contracts/ui-contract.md`；具体 Vue 组件库、路由实现和页面元数据语法不是已确认 ADR，不得自行锁定。


## 11.6 页面生命周期、缓存与版本协调

统一 Vue 壳应在进入路由前校验模块启用状态、UI 插槽版本、用户可见功能及当前工厂上下文。由于插件热停用，页面即使早已装载，也可能在下一次提交时收到 `FEATURE_DISABLED`；客户端必须给出明确操作失败提示，不得偷偷重新提交关键 Mutation。缓存键必须包含身份和工厂作用域，切换工厂/权限时对受影响缓存进行隔离或失效处理。

声明式元数据应具有可验证的 Schema、渲染组件版本、配置依赖与发布来源。若客户覆盖与底座新版字段不兼容，发布流程必须拒绝或明确生成待迁移差异，而不是无声地丢弃字段。关键展示型配置升级应保留上版可恢复状态和独立审计。

## 11.7 可维护性与可测试性

对常用查询/表单定义统一加载态、空态、错误态、受限态、离线态和插件不可用态。自动化 UI 测试至少包括工厂切换、权限变更、动态模块启停、报表配置差异、跨版本 GraphQL 兼容及隔离 iframe 的恶意消息拒绝。最终可选 UI 组件库不应让公开框架契约依赖私有组件内部 DOM 结构。
