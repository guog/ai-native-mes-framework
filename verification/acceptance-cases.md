# 质量属性验收用例目录 · Draft V0.2

**注意：** 本文描述计划中的测试，**全部处于 Not Run**；测试结果必须独立保存，不得以此文件宣称验收完成。

## P0 · 数据一致性与高可用

- **REL-01 已确认事务的主服务器不可恢复损毁**：预置唯一业务请求 ID、关键业务数据、审计、Outbox；在成功响应后损毁主机；验收所有已确认事务在新权威节点/恢复节点可查，零缺失，RTO 符合部署等级。
- **REL-02 网络分区与脑裂**：隔离当前主节点并强制检查仲裁和旧主 fencing；验收任意时刻不出现双权威写入，错误提升必须被阻断。
- **REL-03 同步持久化路径失效**：使同步副本或认证存储失去可靠确认，执行关键 Mutation；验收不返回已提交成功，可安全查询，日志/审计可解释降级模式。
- **REL-04 提交结果未知**：在本地提交后、API 响应前中断连接；同 requestId 重试；验收业务只发生一次，状态能核查，审计及 Outbox 与业务一致。
- **REL-05 标准部署人工恢复**：应用单实例损毁；按恢复运行手册进行操作，验收 RTO≤4h、关键数据零确认丢失。
- **REL-06 HA 自动/受控切换**：应用与数据库节点故障，验收 RTO≤15m、仲裁隔离、数据权威一致。

## P0 · 数据库契约与后台任务

- **DB-01 驱动与基础类型**：四库实际认证版本分别执行 Unicode、decimal、时间、分页、索引、参数化 SQL，用一致业务结果判定。
- **DB-02 迁移与失败回退**：重复迁移、并发升级、DDL 中断、Expand/Contract 跨版本兼容，验证失败状态和数据修复流程。
- **DB-03 Outbox 与审计原子提交**：提交成功/失败/崩溃点注入，验收业务、关键审计、幂等及 Outbox 无不一致。
- **JOB-01 租约过期与旧 Worker 迟到**：双 Worker 竞争、暂停旧持有者后重启；验收旧持有者不能提交权威任务状态且无重复生产效果。
- **JOB-02 任务中断、旧插件版本**：持久检查点和版本恢复，验收队列不丢失且不交给不兼容处理器执行。

## P0 · 安全与插件

- **SEC-01 跨工厂 Query 与 Mutation**：变更 URL/GraphQL 参数/嵌套字段中的工厂标识；验收服务端拒绝跨工厂未授权访问。
- **SEC-02 未授权插件/资源逃逸**：签名篡改、扩大文件/网络/数据库权限、直接写入关键表；验收拒绝并隔离，其他模块稳定。
- **SEC-03 插件停用与 Schema 兼容**：停用期间发送旧 Mutation/继续在途任务，验收新动作被拒绝且任务安全收敛。
- **SEC-04 Agent 授权撤销与审批绕过**：审批参数/资源版本变化、Agent 后台令牌撤销、超配额；验收拒绝新动作、已提交事务不因撤销令牌被暗改。
- **SEC-05 GraphQL 资源攻击**：深度嵌套、无限分页、复杂查询、字段级绕过；验收拒绝并保留其他正常查询能力。

## P1 · 性能、同步与恢复

- **PERF-01 参考负载**：明确 CPU、内存、数据库版本/驱动、数据体量、并发数、查询写入比例和 P95 目标；当前数值均待批准。
- **SYNC-01 长时离线补传**：按容量模型累积事件并断网，恢复后检查点追赶、重复/乱序容忍、对账恢复与主生产响应时间。
- **COMP-01 GraphQL 多版本与多节点**：旧/新 Schema 快照并存和逐步切换，验证路由、旧请求与插件停用错误语义。
